# morpho-blue-py

Python client for the Morpho Blue GraphQL API — lending markets, vaults, positions. Sync + async, Pydantic v2.

## Install

```bash
pip install morpho-blue-py
```

The distribution is `morpho-blue-py`; the import package is `morpho_blue`.

## Quick start

```python
import morpho_blue
```

See the [API reference](api.md) for the full surface.
